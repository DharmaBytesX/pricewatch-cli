## pricewatch

Follow product prices and stock in French stores

### Synopsis

pricewatch shows the prices of the products you track on Pricewatch, and adds
products to track. It uses an API token: create one on Pricewatch's Settings
page, then run "pricewatch auth login".

### Options

```
  -h, --help           help for pricewatch
      --token string   API token (default: $PRICEWATCH_TOKEN or the config file); other users of the computer can see a flag, prefer the variable
      --url string     Pricewatch address (default: $PRICEWATCH_URL, the config file, or https://pricewatch.exe.xyz)
```
